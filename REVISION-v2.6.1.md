# Revision v2.6.1 — Dashboard

- Editor Produk Fresh diperluas untuk mengatur tampilan customer tanpa edit source.
- Pengaturan meliputi emoji produk, nama di menu, judul halaman, deskripsi singkat/lengkap, teks dan warna tombol Deskripsi/Kembali.
- Setiap mode dapat diberi nama tombol, deskripsi, urutan, warna (hijau/biru/merah), serta ditampilkan/disembunyikan.
- Ditambahkan Default Pembuatan Akun: domain, password, nama, dan suffix digit. Nilai ini digunakan oleh backend pada mode Akun Baru dan tidak ditampilkan ke customer.
- Metadata opsi API lengkap dipertahankan sehingga harga mode/paket/durasi tidak kehilangan informasi harga.
- Asset cache version dinaikkan ke v2.6.1.
