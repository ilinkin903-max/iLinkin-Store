# Revision v2.6.3 — Dashboard

- Katalog Jaspay Fresh menampilkan rentang harga API dan preview harga per paket.
- Modal Atur Produk Fresh memiliki bagian **Harga API per Paket** yang responsif.
- Setiap paket menampilkan harga API, harga jual saat ini, dan optional Harga Jual Custom.
- Zoom menampilkan kombinasi mode × durasi; produk lain mengikuti opsi dinamis dari API.
- Add-on API seperti auto-renew tampil terpisah agar tidak dianggap harga paket dasar.
- Layout harga menggunakan grid responsif: desktop multi-column, HP satu kolom tanpa scroll horizontal.
- Asset cache dinaikkan ke v2.6.3.
